## 📌 Overview
**Attendify** is a smart attendance calculator designed for students across all educational institutions. Whether your required attendance is 75%, 80%, 85%, or any other percentage, Attendify helps you track your attendance and plan accordingly. This tool was created specifically to accommodate different attendance requirements that vary between schools, colleges, and universities.

Note: This is an older version of the project, just a prototype. Attendify 2.0 has been released with minimal features, and Attendify 3.0 is coming soon with many added features!
You can check out Attendify 1.6 with partial features at:
**[Attendify 1.6](https://dazzling-dusk-3865b8.netlify.app/)**

## 🚀 Features
- 📊 **Calculate total attendance percentage** based on your classes attended
- 📅 **Find out how many classes you can skip** while maintaining required attendance
- 🎯 **Support for different percentage thresholds** (75%, 80%, 85%, etc.)
- 🔢 **Easy-to-use input system** for quick calculations
- 📱 **Responsive and user-friendly** design for all devices

## 📦 Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/attendify.git
   ```
2. Navigate to the attendify folder:
   ```sh
   cd attendify
   ```
3. Navigate to the project folder:
   ```sh
   cd project
   ```
4. Install dependencies (if applicable):
   ```sh
   npm install
   ```
5. Run the project (if applicable):
   ```sh
   npm start
   ```

## 🖥️ Usage
1. Enter the total number of classes conducted
2. Enter the number of classes attended
3. Select your required attendance percentage (75%, 80%, 85%, etc.)
4. The calculator will display your current attendance percentage
5. See how many more classes you can afford to miss
